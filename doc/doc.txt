LAKEHOUSE API REFERENCE

CORE - Configuration
lakehouse.core.config.scan_settings_folder()                      - List all .json files in settings/{color}/
lakehouse.core.config.extract_destination_tables()                - Extract destination_table from all configs

CORE - Utilities
lakehouse.core.utils.read_json_and_decode()                       - Read JSON file -> put into a variable
lakehouse.core.utils.get_table_schema()                           - Get schema from table, optionally drop columns
lakehouse.core.utils.ensure_table_exists()                        - Create table (w/schema) if missing

ALL/BRONZE/SILVER - Transforms
lakehouse.core.transform.metadata.add_timestamp_column()          - Add current_timestamp() column
lakehouse.bronze.transform.file.add_source_metadata()             - Add _metadata as named column
lakehouse.bronze.transform.derived.add_ingest_time_from_path()    - Extract datetime from file_path via regex, add as derived_ingest_time column
lakehouse.silver.transform.columns.rename_columns()               - Apply column name mapping
lakehouse.silver.transform.columns.cast_data_types()              - Cast columns to target types
lakehouse.silver.transform.metadata.add_row_hash()                - SHA256 hash of specified columns
lakehouse.silver.transform.metadata.flatten_source_metadata()     - Flatten nested source_metadata struct

BRONZE - Utilities
lakehouse.bronze.utils.get_latest_file_path()                     - Find latest file matching date pattern (YYYYMMDD)

BRONZE LAYER - Data Ingestion (local)
lakehouse.bronze.ingest.local.from_file()                         - Ingest files from landing zone via Auto Loader
lakehouse.bronze.ingest.local.from_inbox()                        - Move files from inbox to landing, then ingest
lakehouse.bronze.ingest.local.from_pdf()                          - Read latest PDF from volume, parse with ai_parse_document, write to Delta (batch)

BRONZE LAYER - Data Ingestion (net)
lakehouse.bronze.ingest.net.from_url()                            - Download file, land, then ingest
lakehouse.bronze.ingest.net.from_sftp()                           - Download from SFTP, land, then ingest
lakehouse.bronze.ingest.net.from_rest()                           - Call REST API, land JSON response, then ingest

SILVER LAYER - Data Ingestion
lakehouse.silver.ingest.from_table.upsert.without_delete()        - Stream bronze➜silver with upsertByPK()
lakehouse.silver.ingest.from_table.upsert.with_delete()           - Stream bronze➜silver with fullSyncMerge()
lakehouse.silver.ingest.from_table.merge.with_delete()            - Stream bronze➜silver with fullSyncMergeSQL()
lakehouse.silver.ingest.from_table.history.scd2()                 - Stream bronze➜silver with scd2UpsertByBusinessKey()
