LAKEHOUSE API REFERENCE

CORE - Configuration
lakehouse.core.config.scan_settings_folder()                      - List all .json files in settings/{color}/
lakehouse.core.config.extract_destination_tables()                - Extract destination_table from all configs

CORE - Utilities
lakehouse.core.utils.read_json_and_decode()                       - Read JSON file from workspace -> put into a variable
lakehouse.core.utils.get_table_schema()                           - Get schema from table, optionally drop columns
lakehouse.core.utils.ensure_table_exists()                        - Create table (w/schema) if missing

ALL/BRONZE/SILVER - Transforms
lakehouse.core.transform.metadata.add_timestamp_column()          - Add current_timestamp() column
lakehouse.bronze.transform.metadata.add_source_metadata()         - Add _metadata as named column
lakehouse.silver.transform.columns.rename_columns()               - Apply column name mapping
lakehouse.silver.transform.columns.cast_data_types()              - Cast columns to target types
lakehouse.silver.transform.metadata.add_row_sha_checksum()        - SHA256 hash of specified columns
lakehouse.silver.transform.metadata.flatten_source_metadata()     - Flatten nested source_metadata struct

BRONZE - Utilities
lakehouse.bronze.utils.get_latest_file_path()                     - Find latest file matching date pattern (YYYYMMDD)

BRONZE LAYER - Data Ingestion
NOTE: All files must be decompressed before ingestion. from_url(), from_inbox(), and from_file() require decompressed input.
lakehouse.bronze.ingest.files.from_file()                         - Ingest files from landing zone via Auto Loader
lakehouse.bronze.ingest.files.from_url()                          - Download file, land, then ingest
lakehouse.bronze.ingest.files.from_inbox()                        - Move files from inbox to landing, then ingest

SILVER LAYER - Data Ingestion
lakehouse.silver.ingest.from_table.upsert_by_pk()                 - Stream bronze➜silver with upsertByPK()
lakehouse.silver.ingest.from_table.scd2_upsert_by_business_key()  - Stream bronze➜silver with scd2UpsertByBusinessKey()
lakehouse.silver.ingest.from_table.full_sync_merge()              - Stream bronze➜silver with fullSyncMerge()
lakehouse.silver.ingest.from_table.full_sync_merge_sql()          - Stream bronze➜silver with fullSyncMergeSQL()
lakehouse.silver.ingest.from_table_scd2()                         - Stream bronze➜silver with scd2UpsertByBusinessKey()

JOBS - Constraints
file_version_history_loop and transaction_history_loop require concurrency: 1 because
both write to a shared Delta table and parallel iterations will cause Databricks write
conflicts.
