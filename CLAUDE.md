# PR Comments
- 10 words max, no headings, one short sentence

# Commit Messages
- Always replace merge message
- Extract PR number
- Output exactly: `Merge PR <number>`
- No other text

# Code Modifications
- Only modify lines required for the requested change
- Preserve all formatting, spacing, and alignment on unchanged lines
- Do not reformat, normalize, or touch whitespace outside edited lines
- When editing a line, preserve its original alignment
- Treat formatting as immutable unless user explicitly requests changes
